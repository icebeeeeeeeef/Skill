# Evidence Levels

Use these labels in notes and summaries.

`first_party`:
Official docs, source code, tests, RFCs, design docs, releases, maintainer comments, or official project blogs.

`official_implementation`:
Code or examples from the upstream project or paper authors.

`paper`:
Published paper or preprint. Treat claims as paper claims until implementation and reproducibility are checked.

`engineering_practice`:
Company/team/maintainer practice writeups with versions, workload context, metrics, and trade-offs.

`community_analysis`:
Zhihu, Juejin, WeChat, personal blogs, 博客园, or similar analysis. Useful for explanations and recall; verify key facts upstream.

`repost`:
Republished or SEO content. Use only for pointer discovery, not as decision evidence.

## Claim Separation

Mark whether each claim comes from:

- Search snippet.
- Full article text.
- README statement.
- Verified source code.
- Test or benchmark result.
- Paper result.
- Author opinion.

Do not merge these into one confidence level.

# 重放 issue 模板（replay 模式使用）

```markdown
### [Issue] <用户视角的标题，不暗示方案>

**环境**：模型、硬件、版本 / 当前设计所处的阶段
**负载**：请求数、输入输出长度分布、到达模式

**现象**：
（用户看到了什么：延迟、吞吐、OOM、错误……）

**数据**：
（具体数字，例如：并发 64 时显存利用率只有 40% 就 OOM；TTFT P99 = 8s）

**复现步骤**：
1. ……

**期望**：
（用户想要的结果，不写实现方式）
```

写作要求：像真实用户或同事提的 issue；具体、有数字；不出现方案名词，不写"请设计一个 XXX 机制"。

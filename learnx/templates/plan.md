# 学习计划模板

属性：名称、类型、状态、时间范围、目标、完成标准、对应矛盾/节点、触发方式、复盘。

正文：

```markdown
## 背景
（为什么现在做这个：项目卡点 / 地图盲区 / 面试需要 / 兴趣）

## 目标
（做完后我能做到什么——用"能预测 / 能实现 / 能解释"描述，不用"了解"）

## 完成标准（可检验）
- [ ] 指标或实验结果：……
- [ ] 不看资料的重建：……
- [ ] 输出：问题卡片 / 工程日志 / 一篇说明

## 材料
（来自材料清单；读法：通读 / 精读哪几节）

## 步骤
- [ ] ……

## 回流到项目的产出
（深挖和地基单元必填：项目里的一个功能、一组对比实验或一篇带数据的笔记）

## 进度记录
（日期 + 一句话；replay 的轮次进度也写在这里）

## 复盘
```
